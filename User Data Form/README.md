# 🧾 User Data Form

🚀 **Day 02 of 30DaysOf30Projects**

A simple web form that collects user input (Name, Age, Email) and displays it instantly after submission. Built using **HTML**, **CSS**, and **JavaScript**.

## ✨ Features

- User-friendly input form
- Validates required fields (Name, Age, Email)
- Displays submitted data dynamically
- Clean and responsive design

## 🚀 How to Use

1. Open the webpage in your browser.
2. Fill in your **Name**, **Age**, and **Email**.
3. Click **Submit**.
4. Your entered data will appear below the form.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
