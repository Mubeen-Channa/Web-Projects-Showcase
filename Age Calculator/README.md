# 📅 Day 05: Age Calculator

This is a simple **Age Calculator** built using **HTML, CSS, and JavaScript**.  
The user can input their date of birth, and the app will instantly calculate their current age in **years, months, and days**.

<br>

## 🔧 Features

- 🗓️ Enter your birth date  
- ⚡ Instant age calculation  
- 🎨 Responsive and clean UI  
- 🧮 Accurate age breakdown in years, months, and days

<br>

## 📁 Files

- `index.html` – Structure of the Age Calculator  
- `style.css` – Styling and layout  
- `script.js` – Logic for calculating age

<br>

## 🚀 How to Use

1. Clone the repository or download the project folder  
2. Open `index.html` in your browser  
3. Enter your date of birth and see your age instantly!
