# 🌗 Dark/Light Mode Switcher

A simple, responsive Dark-Light theme switcher web app built using HTML, CSS, and JavaScript. This app lets users toggle between dark and light modes with a smooth transition and an intuitive switch UI.

<br>

## 🚀 Project Info

- 👨‍💻 Day 03 of `#30DaysOf30Projects`
- 💡 Toggle between **Dark** and **Light** themes
- 🌈 Smooth transitions and responsive design
- 🌐 Uses [Font Awesome](https://fontawesome.com/) icons for visual theme indication

<br>

## 📁 Project Structure

- `index.html` – Structure of the app
- `style.css` – Styling with CSS variables

## 🔧 Features

- 🌓 Toggle between dark and light themes
- ✨ Real-time icon and label updates (`🌙 / ☀️`)
- 🎨 CSS variables for easy theme customization

## 🛠️ Tech Stack

- HTML5
- CSS3 (Custom Properties & Transitions)
- JavaScript (DOM Manipulation)
